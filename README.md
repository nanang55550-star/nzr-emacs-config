# nzr-emacs-config
## Only Linux 

## konfigurasi apa saja yang berada di emacs ini 
Konfigurasi ini sudah mencakup Performa (GCMH & Byte-compile), Visual (Wombat Black & Powerline Cache), Coding (Company, Flycheck, Yasnippet, Indent Guides), dan Navigasi (Shortcut F-keys & Windmove).

## what configurations are in this emacs 
This configuration includes Performance (GCMH & Byte-compile), Visual (Wombat Black & Powerline Cache), Coding (Company, Flycheck, Yasnippet, Indent Guides), and Navigation (Shortcut F-keys & Windmove).

## penggunaan 
kalian tinggal copy file emacs di Repository ini lalu ke Linux, lalu jalankan perintah ini 
```bash
nano ~/.emacs
```
lalu kalian paste teks yang kalian copy tadi yang di file emacs di Repository ini 

## use
You just copy the emacs file in this repository to Linux, then run this command 
```bash
nano ~/.emacs
```
then you paste the text that you copied earlier in the emacs file in this repository
